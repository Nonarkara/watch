# Home: editorial column grid

Owner-approved repair: boxes fit their information; keep the animated city,
credited art, typography, evidence, links and section sequence. No new palette.

Attention order: artwork → headline and browse action on its exit → evidence.
The city is the setting, not a map-based operating surface. Its gutters stay
visible; reading content stays on opaque theme-aware paper.

## Changes and preservation

- Align every section to the content shell; remove negative-margin bleed.
- Natural-width statistics, no equal stretched tiles and no orphan last counter.
- Keep all four evidence commitments in a named native disclosure.
- Keep the compact attention sampler; its ranking/source action opens, scrolls
  and focuses the detailed reading surface. No silent deletion of qualifiers.
- Object photograph and verdict form one group. Narrative and dossier/compare
  actions share a reading row below; long text cannot stretch an image column.
- Guide and curiosity links become reading rows; illustrated lists retain photos.
- Fixed-blue footer receipt uses constant white text in either theme.

## Executable evidence

`npm run verify:home` uses a real browser at 375×844, 390×844, 639×900, 640×900,
768×900, 1024×900, 1280×720 and 1440×900. Set `WATCH_BROWSER_BIN` when
agent-browser is not on PATH. `WATCH_BEFORE_URL` optionally records the old site;
`WATCH_PROOF_DIR` selects the screenshot and JSON receipt directory.

Task-specific gates: stats ≤125px wide; no one-item stat row; ledger ≤190px below
880px and ≤140px above; guide section ≤700px on phone and ≤440px otherwise;
illustrated hot list ≤920px on phone and ≤600px otherwise. Side-by-side Spotlight
photo-column slack ≤100px (only ≥880px; a stacked photo is not column slack).
Sections align to the opening within 2px; browse action stays on the first screen.
Ranking results receive focus and land at the viewport top within pixel rounding.
The original equal-track statistic layout is restored locally and must fail the
same width gate. Tests also open the commitments and check the dark footer.

These checks do not certify every user journey, every image source, or human
usability. Independent pixel review remains required; geometry receipts are not
permission to waive a visual defect.
